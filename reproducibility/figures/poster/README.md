# Poster figures

Script: `generate_poster_figures.py`

Command:

```bash
python reproducibility/figures/poster/generate_poster_figures.py
```

Outputs are written to `reproducibility/outputs/poster_figures/`:

- `action_profiles.{pdf,png}`
- `evidence_domains.{pdf,png}`
- `case_pathways.{pdf,png}`
- `workflow.{pdf,png}`

The figures use the same validated scientific values as the paper-derived artifacts. No poster-only scientific result is introduced.
